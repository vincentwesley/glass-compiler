        Every .wast file of the WebAssembly 1.0 core testsuite, as published by the WebAssembly working
        group. A command is a module to load, a call to check, or a module that must be rejected as malformed, invalid
        or unlinkable. The recorded column comes from the command-line run; press the button to run the same files with
        the same machine, here in your browser.
