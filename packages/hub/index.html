Glass

Computers you can see through.

A series by Vin's Atelier

Small machines, built from scratch, with the glass left off.

Each Glass project is a real piece of computing: a compiler, a virtual machine, a console, a kernel. You can watch it work and click any part to see where it came from and where it goes next. They're graded by real test suites, and the scores are shown on each page.

01 The pipeline

The projects connect. A Pane program (through Glass Compiler) or a C program (through Small C) compiles to WebAssembly, runs in the Glass Wasm debugger and, later, boots on Glass Kernel.

02 The series

Live projects open straight into a working demo. Planned ones are drawn dashed until they exist.

03 How it's made

  • Open source, one repo. Every project is its own package with its own tests, sharing one debugger kit.
  • Graded, not claimed. Scores come from official test suites and are recorded by a script, never typed in.
  • Private by design. Static pages, no accounts, no tracking, no requests to other sites. Your code stays in your browser.
